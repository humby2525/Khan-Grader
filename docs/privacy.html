Khan Grader Privacy Policy

Last updated: August 22, 2026

Khan Grader helps teachers read Khan Academy activity minutes, review calculated grades, and send approved assignment and grade information to Schoology.

Data the extension handles

The extension may handle teacher-entered class settings, Khan Academy class and student identifiers, student names, activity and exercise minutes, Schoology section and enrollment information, assignment information, grades, and a teacher's Schoology API consumer key and secret.

How data is used

This data is used only to capture Khan Academy activity selected by the teacher, match students, calculate and preview grades, prepare Schoology assignments, and send grades after the teacher confirms the action.

Storage and sharing

Settings, credentials, and captured results are stored locally in the Chrome profile using chrome.storage.local. They are not sent to or stored on a server operated by the developer. Data is exchanged directly with Khan Academy and Schoology only when needed for features the teacher initiates. The extension does not sell data, use it for advertising, or share it with data brokers.

Authentication

The extension uses the teacher's existing signed-in Khan Academy browser session. It does not collect or store a Khan Academy or Google password. Schoology API credentials entered by the teacher are stored locally in the Chrome profile and sent only to Schoology to authenticate API requests.

Data retention and deletion

Local data remains in the Chrome profile until the extension's stored data is cleared or the extension is removed. Removing the extension from a Chrome profile deletes its local extension storage under Chrome's normal extension data behavior.

School responsibilities

Teachers and schools are responsible for ensuring they are authorized to access and process student information and for following their institution's privacy, records, and technology policies.

Changes

This policy will be updated when the extension's data practices change. The updated date at the top identifies the current version.

Contact

Questions about this policy may be submitted through the repository's GitHub Issues page.
